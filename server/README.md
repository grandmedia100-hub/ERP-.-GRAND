# دليل تشغيل الخادم (Server Guide)

## المتطلبات
- Node.js مثبت على الجهاز
- ملف نسخة احتياطية من البيانات القديمة (backup.json)

## خطوات التشغيل للمرة الأولى

### 1. ترحيل البيانات القديمة
قبل تشغيل الخادم، قم بترحيل بياناتك الحالية:

```bash
cd server
node migrate.js path/to/backup.json
```

سترى رسائل توضح عدد السجلات التي تم ترحيلها لكل جدول.

### 2. تشغيل الخادم
```bash
npm start
```

سترى:
- ✅ تم الاتصال بقاعدة البيانات بنجاح
- 🚀 الخادم يعمل على المنفذ 4000

### 3. الوصول للخادم
- من نفس الجهاز: `http://localhost:4000`
- من أجهزة أخرى: `http://SERVER_IP:4000`
  (استبدل SERVER_IP بعنوان IP الخاص بجهاز الخادم)

## اختبار الخادم
افتح المتصفح واذهب إلى:
```
http://localhost:4000/api/health
```

يجب أن ترى: `{"status":"OK","message":"الخادم يعمل بنجاح"}`

## إيقاف الخادم
اضغط `Ctrl+C` في نافذة الأوامر

## المنافذ (Ports)
- الخادم: المنفذ **4000**
- تطبيق الويب: المنفذ **3000** (كما هو)

## استكشاف الأخطاء
- إذا ظهر خطأ "Port already in use"، تأكد من عدم تشغيل الخادم مرتين
- إذا فشل الاتصال، تحقق من جدار الحماية (Firewall)

## النسخ الاحتياطي
قاعدة البيانات موجودة في ملف:
```
server/mediahive.db
```

قم بنسخه احتياطياً بشكل دوري!
