# MediaHive ERP v10.1.0 Release Notes
**Date:** February 11, 2026
**Version:** 10.1.0

## 🚀 New Features & Improvements

### 1. Enhanced Invoicing UI
- **Searchable Dropdowns:** Replaced standard dropdowns with searchable input fields for:
  - **Customers** in Sales Invoices
  - **Suppliers** in Purchase Invoices
  - **Products** in Invoice Filtering
- This makes selecting from large lists much faster and more user-friendly.

### 2. Print Layout Optimization
- **A4 Compatibility:** enhancing the print layout for:
  - **Quotations**
  - **Sales Invoices** (Planned)
  - **Purchase Invoices** (Planned)
- **Whitespace Removal:** Automatically removes excessive whitespace to fit content perfectly on A4 paper.
- **Grayscale Support:** Improved support for black & white printing.

### 3. Job Costing Documentation
- Added comprehensive guides for:
  - **Simplified Job Costing:** Direct cost tracking per order.
  - **Advanced Job Costing:** Full overhead allocation and profit analysis.

## 🐛 Bug Fixes & Performance
- Optimized search performance for customer/supplier selection.
- Fixed layout issues in quotation printing.

## 📦 Build Information
- **Clean Version:** `dist-electron-v10.1-clean` (Empty Database)
- **Data Version:** `dist-electron-v10.1-data` (With Existing Data)
